# 拍摄位置与地名详情

更新日期：2026-11-11。

本次实现把所有媒体共用的 Singapore 示例坐标替换为按文件读取的位置。它不修改去重、重命名或操作日志中的媒体身份模型。

## Android 行为

- 打开媒体详情时才在 IO 线程读取位置；浏览列表和重复扫描不会批量读取 GPS 或请求地名。
- 照片使用 `ExifInterface.latLong`，视频使用 `MediaMetadataRetriever.METADATA_KEY_LOCATION` 的 ISO 6709 值。
- MediaStore 的原始位置信息需要 `ACCESS_MEDIA_LOCATION`；未授权时显示专门入口，由用户触发系统权限请求。拒绝后可前往应用权限设置；从设置返回会重新读取。此权限用于媒体中的位置，不申请设备实时定位权限。
- 指定文件夹 / SAF URI 按已有读取授权读取。无 GPS、读取失败、失去读取权限分别反馈，不伪造坐标或地点。
- 获得有效坐标后调用 Android `Geocoder`。Android 13 以上采用异步接口，Android 11–12L 在 IO 线程使用旧接口；设备没有地理编码服务时显式提示失败。
- 地名、完整地址和 DMS 坐标分别展示。成功地名按精确坐标和语言缓存，最多 64 项；无结果、错误和取消不缓存，允许重试。缓存仅在当前应用会话内存在。
- 查询失败、超时或无地址时保留坐标及复制/地图入口，不影响媒体浏览。系统服务的地点精度由返回数据决定，不保证精确到某个景点。
- 用户点击“加载拍摄位置地图”后，使用 OpenStreetMap 的 HTTPS 嵌入地图，标记使用该媒体的真实坐标。显示来源署名，地图失败时保留地名和坐标及重试入口；关闭详情销毁 WebView。
- “在外部地图查看”打开该坐标的 OpenStreetMap 页面。复制坐标使用十进制度，适合粘贴到地图应用。

地名查询可能由系统联网发送坐标，加载地图会向 OpenStreetMap 发送坐标；不会发送照片或视频。GPS 读取本身在本机完成。离线或无地理编码服务时不承诺自动得到地名。

## HTML 评审原型

打开 `docs/ui-prototype.html` 即可直接使用，不依赖开发服务器或 Android 模拟器。使用 HTTP 预览时复制坐标走浏览器剪贴板接口，接口不可用时显示待复制坐标。

- 第一张缩略图：地图、演示地名、地址和坐标。
- 第二张缩略图：无 GPS，不显示地图。
- 第三张缩略图：地名查询失败，保留坐标，点击“重新查询示例”演示恢复。
- 地图明确标记为示意，地名明确标记为静态演示。`1° 24′ 20.06″ N, 103° 47′ 40.28″ E` 不用于证明对应某个具体景点。
- 手机宽度下详情改为单列，打开详情锁定背景滚动，关闭恢复位置。

## 验证范围

单元测试覆盖坐标范围、南西半球、DMS 进位、ISO 6709 解析、地名成功缓存、失败/取消后重试、缓存容量、坐标隔离和地图坐标顺序。

构建检查：

```powershell
.\gradlew.bat --no-daemon --max-workers=2 :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:compileDebugAndroidTestKotlin
```

浏览器实测覆盖 HTML 的地名/无 GPS/失败三态和重试，并检查手机宽度布局。Android 仪器测试增加应用自身缓存目录内生成的 EXIF JPEG 样本；不会操作个人媒体。

本轮检查结果：67 项单元测试通过，失败 / 错误 / 跳过均为 0；Lint、调试 APK 构建和仪器测试 Kotlin 编译通过。手机 390 × 844 视口下详情无横向溢出，打开详情锁定背景，关闭与 Escape 均恢复焦点；失败示例可以重试切换到有地名状态。预览截图保存在 [ui-location-preview.jpg](ui-location-preview.jpg)。

后续已按用户要求在 Android 16 / API 36 无窗口模拟器中执行全部 28 项设备测试并通过。真实地名解析成功，OpenStreetMap 页面、MapLibre Canvas 及 4 个返回 HTTP 200 的瓦片请求均已核对；但截图仍未显示地图像素，不能视为地图视觉验收通过。详情、无 GPS、回收站、重命名与更新流程的验证范围见 [0.4.0 验证记录](releases/v0.4.0-validation.md)。真机上的媒体位置权限拒绝/永久拒绝交互及地图绘制仍待验收。
