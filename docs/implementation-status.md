## 已实现

- Android 11+ 单 app 模块，Kotlin / Compose / Material 3。
- SDK 36，JDK 17，固定 Gradle Wrapper 与分发包校验摘要。
- 媒体、重复组、推荐、命名预览和操作记录共享模型。
- 无 `INTERNET` 和所有文件访问权限，媒体变更走系统确认；APK 合并权限已核对。播放器依赖带有网络状态读取权限，不代表具有互联网访问能力。

- 精确去重：大小分桶、流式 SHA-256、最终字节核对，可取消；同组代表仍参与版本比较，避免隐藏压缩版本。
- 疑似版本候选：方向归一化、差异哈希和亮度比较，组内两两核对；视频检查严格时长及首尾在内的七个时间点。动图/已识别实况照片不以单帧做版本判断。
- 照片以像素优先给出建议，细节冲突不强选；视频同时考虑可比较元数据、采样细节和单位像素码率，未知或用途差异默认全部保留。
- 视频色彩/色深读取使用平台元数据，并补充 Media3 SPS 解析；未知信息保留未知，不猜测为 SDR。
- 真实媒体与相册选择、三类结果、推荐原因、人工内容复核和保留项。更换保留项会清除旧确认。
- 图片任意配对放大，视频任意配对共享播放/进度、切换收听；后台暂停，关闭释放。
- 随机和自定义模板命名预览、稳定排序、扩展名保留、NFC/大小写/跨媒体目录碰撞防护。预览到提交保持同一份计划。
- 系统写授权、回收站和恢复；逐项执行结果持久化到 Room，支持展开全部明细和尝试撤销。
- 准备校验的单项失败也有日志；批次内保护保留项，单次最多 200 项且不截断。
- 等待系统回调的计划通过保存状态恢复；中断对账不重放，授权取消不计成功；已可能生效但核对取消的项留待对账。

## 验证边界

- 用户已确认“先提供 APK，稍后自行安装”，因此真实 Android 14+ 手机、厂商回收站行为与系统部分媒体重选留待用户验收，未冒充已完成。
- Android 11–13 代码分支未做对应设备实测；目前自动化设备是 Android 16 / API 36 模拟器。
- 大相册/长视频耗时、内存峰值、放大字体与完整 TalkBack 验收尚未完成；选择控件已有可访问语义，窄屏选项使用可换行布局。
- 有限画面采样及音轨格式信息不能证明每一帧和声音内容完全相同，疑似版本仍必须人工对比；未声称零误报、零漏报或检测所有编辑差异。
- 本次为调试测试包，尚未进行发布包体积优化或商店发布验收。

交付判断以以上真实构建与测试证据为准，设计原型验证未被用作 Android 功能通过的依据。
