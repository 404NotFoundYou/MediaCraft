# MediaCraft UI 静态原型

## 原型阶段目标

本原型用于重新设计 MediaCraft 的 UI 布局和操作层级，同时保留当前项目已有业务能力。当前视觉偏好为明亮、简洁的专业媒体库：以媒体内容为主，使用稳定的导航、清楚的状态反馈和克制的工具层级。

本目录保留独立 HTML 静态原型及其阶段验收记录。原型已获确认，后续 Flutter 改造见 [生产实现映射](IMPLEMENTATION.md)，最终设备、测试和构建证据见 [UI 验证记录](UI-VERIFICATION.md)。下文“不修改源码”和模拟动作说明仅描述原型交付阶段，不代表后续生产实现的当前状态。

## 打开方式

原型零构建、无包管理依赖，可直接双击本目录的 `index.html` 打开。

也可以从仓库根目录启动本地静态服务器：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory docs/design/mediacraft-ui
```

然后在浏览器打开：

```text
http://127.0.0.1:8000/
```

## 原型范围

原型包含 28 个主页面与状态，分为四组：

- 日常浏览：媒体库、相册、标签、探索、搜索、照片地图。
- 查看与创作：照片查看器、视频播放器、媒体详情、图像编辑、特殊媒体、幻灯片、设备投放、壁纸。
- 整理与维护：工具、文件夹、统计、重复媒体、扫描、重复项复核、回收站、保险库。
- 设置与系统：设置、隐私与权限、关于、系统选择器、首次使用、空态与异常。

建议的默认底部导航为 4 项：

1. 媒体
2. 相册
3. 探索
4. 工具

这是新的默认信息架构建议。项目已有的导航编辑能力继续保留，用户仍可调整支持的页面入口。

## 关键评审路径

### 日常浏览

`媒体 -> 搜索/筛选 -> 选择媒体 -> 查看器 -> 详情或编辑`

重点检查浏览态、选择态和查看态是否层级清楚，以及现有媒体操作是否仍有稳定入口。

### 地图与百度隐私

`探索 -> 照片地图 -> 地图样式 -> 百度普通/卫星 -> 隐私说明 -> 同意或切换 OpenFreeMap`

百度地图同意仅在选择百度样式时出现。撤回入口位于“隐私与权限”；所有地图和授权结果均为静态模拟。

### 重复媒体清理

`工具 -> 重复媒体清理 -> 选择扫描范围 -> 扫描 -> 复核重复项 -> 手动勾选待清理项 -> 最终字节复核 -> 回收站`

每组默认首项为保留项，用户可主动更换；待清理选择初始为空，不自动全选。原型模拟文件变化、读取问题和处理失败等状态，不读取或移动真实文件。

### 回收站与隐私

`工具 -> 回收站 -> 选择项目 -> 恢复或永久删除`

`设置 -> 隐私与权限 -> 系统权限/存储授权/隐藏规则/回收站/搜索历史/百度授权`

关闭回收站时需要先处理保险库依赖和现有回收站内容。原型只演示确认流程，不执行真实删除。

### 设置与数据维护

`设置 -> 八个设置分类 -> 搜索设置项`

`设置 -> 设置导入/导出 -> 选择封面、动态相册、收藏与设置`

八个分类为导航、缩略图、查看器、视频、隐私、无障碍、显示、语言与格式。导入、导出、目录选择、缓存清理和更新检查均为模拟动作。

### 首次使用与异常

`首次使用 -> 阅读条款 -> 接受 -> 权限状态`

`空态与异常 -> 权限受限/空图库/初始化失败/无重复/文件变化/清理失败`

初始化失败状态保留错误详情、问题反馈和数据库导出入口。原型中的错误、堆栈和导出结果均为示例。

## 数据与素材边界

- 所有媒体、数量、容量、日期、路径、位置、权限、更新、缓存和操作结果均为模拟数据。
- 原型不会连接 Android 设备、MediaStore、SAF、百度地图 SDK、GitHub API 或其他系统服务。
- 原型不会读取用户媒体，不会修改文件，不会申请权限，也不会执行移动、删除、分享、编辑、导入、导出或更新。
- Flutter 源码未因本原型修改；设备端业务流程和不同 Android 版本行为尚未验证。
- 示例照片已离线保存在 `assets/`，来源和原始链接记录在 `assets/SOURCES.txt`。素材来自 Unsplash，未使用用户媒体。
