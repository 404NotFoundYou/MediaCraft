# Android 14 及以上测试说明

本版为 MediaCraft 0.1.0 调试签名测试 APK。测试包位于 `artifacts/MediaCraft-0.1.0-debug.apk`，工程兼容下限为 Android 11；首轮安装目标已确认是 Android 14 或更新版本。

## 安装与首次打开

1. 把 APK 传到手机并打开，按手机系统提示允许该来源安装。
2. 首次打开后在“去重”页点击“授权”。可以只选择部分媒体，或授予照片/视频的完整读取范围。
3. 部分授权时，界面应显示“仅能访问部分媒体”；结果只覆盖当前授权项目。

应用无需登录。媒体在本机处理，未申请 `INTERNET` 或所有文件访问权限。部分系统组件可能另行显示自身的系统授权界面。

## 验证主要流程

建议在独立测试相册中放入几份可核对的照片、视频副本，便于确认结果。

- 完全重复：同一文件改成不同名称，扫描后应归入“完全重复”。每组至少保留一份；确认清单应列出保留和待回收名称。
- 照片版本：同一构图的原图与缩小版本，扫描后可出现“照片版本”候选；建议原因应写清像素尺寸。点击“对比”可选择两份并放大查看，内容复核之前不能处理。
- 视频版本：同一完整片段的高低清版本，可出现“视频版本”候选。元数据、细节或单位像素码率互有矛盾时不强制推荐。对比中可共享播放和进度，并切换收听两份声音。
- 重命名：选择文件，设置随机命名或自定义模板，生成预览后确认。实际名称应与预览一致，扩展名和媒体内容不变；取消系统授权不得改名。
- 记录：展开逐项结果，核对名称、状态与原因。成功重命名后可尝试恢复原名，成功回收后可尝试恢复文件；系统仍会检查当前文件、权限和名称占用。

## 本机验证的边界

自动化验证设备为 Android 16 / API 36 模拟器。它不等同于你的真实手机。

真机仍需关注：Android 14 部分媒体选择与重新选择、厂商回收站和媒体提供方差异、长视频解码、大相册扫描时间、放大字体与 TalkBack。Android 11–13 版本分支尚未做对应设备实测。

疑似同内容匹配使用有限采样，可能误报或漏报；视频多点采样和音轨格式检查不能证明每个画面与声音都完全相同。视频色彩等信息未知时保持保守，不按文件大小直接下画质结论。最终是否处理仍由用户对比复核。

具体构建、测试数量和 APK 摘要见 [开发验证记录](implementation-status.md)。
