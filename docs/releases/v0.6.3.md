# MediaCraft v0.6.3 百度版

发布日期：2026-11-16。应用版本为 `0.6.3+187`，GitHub 发布标签为 `v0.6.3-baidu`。

## 更新内容

- 图库加载失败时显示错误并允许重试；文件操作报错后恢复媒体监控。
- 重命名会校验模板、日期格式和文件名，阻止空名称及跨目录路径；批量元数据计算限制并发。
- 修正多目标空间估算、导出收藏迁移及大目录冲突检查。
- 修复视频初始化和退出竞态、媒体会话更新顺序、播放失败等待、动画帧释放及大图旋转/翻转分块。
- 修复百度地图标记和坐标缓存累积、轨迹失败恢复，以及重复媒体清理的进度和复核读取成本。
- 强化 SDK/flavor 一致性检查、失败回滚和发布质量门禁。

## 安装包

本次发布仅提供百度地图 flavor，包名为 `com.mediacraft.app.baidu`。

| ABI | 文件 | versionCode |
| --- | --- | ---: |
| arm64-v8a | `MediaCraft-0.6.3-baidu-arm64-v8a-release.apk` | 18702 |
| armeabi-v7a | `MediaCraft-0.6.3-baidu-armeabi-v7a-release.apk` | 18701 |
| x86_64 | `MediaCraft-0.6.3-baidu-x86_64-release.apk` | 18704 |

大多数近期 Android 手机使用 arm64-v8a。附件中的 `SHA256SUMS.txt` 用于核对下载文件。
从本版本起，GitHub Release 默认提供百度版正式包。正式 Release 必须成为 GitHub Latest Release，供已安装旧版本检测更新。2026-11-16 已将 `v0.6.3-baidu` 设为 Latest，并核验接口返回该版本；发布附件保持不变。此要求不改变本地开发默认使用 `libre` flavor 的约定。

Release 交付前逐个核对包名、版本、单一 ABI、百度 SDK/C++ 运行库、发布签名和百度 AK 配置；校验记录与构建产物保存在本地发布目录。
