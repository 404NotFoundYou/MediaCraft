# MediaCraft 0.2.0

- 新增“检查更新”入口，手动读取 GitHub 正式 Release。
- 支持应用内下载 APK、显示进度和取消；下载后由用户打开 Android 系统安装界面。
- 安装前核对 SHA-256、包名、版本、最低系统和已安装应用签名，阻止错误文件与降级。
- 支持未知来源安装授权后重新校验，以及进程重建后的下载记录恢复。
- 媒体仍只在本机处理；只有手动检查和下载更新时访问 GitHub。
- 保留照片/视频去重与质量建议、批量命名、系统回收站和操作恢复。

## 从 0.1.0 调试版迁移

本版开始使用专用正式发布签名，与先前的 0.1.0 调试 APK 不同。若已经安装调试版，需要先卸载后安装本版；卸载会清除应用操作记录，本机相册中的照片和视频保留。之后的正式版本将沿用此签名，可通过应用内更新。

## 安装

下载 `MediaCraft-0.2.0.apk` 并按系统提示安装，最低 Android 11，建议 Android 14 或更新版本。`update.json` 供应用内更新读取，`.sha256` 用于文件校验。
