# MediaCraft v0.6.7 百度版

应用版本为 `0.6.7+191`，正式标签为 `v0.6.7`。

## 本次调整

- 限制离屏图像队列积压，减少图库搜索和连拍、RAW 堆叠中的重复计算。
- 增量查询成功后才推进同步基线，冷启动一次核对缓存条目的删除和路径变化。
- 重复清理结果按需加载并节流进度通知，百度地图减少覆盖物刷新，更新检查超时后可重试。

## 正式安装包

百度地图 flavor 包名为 `com.mediacraft.app.baidu`，本地默认开发 flavor 仍为 `libre`。

| ABI | 文件 | versionCode |

标签工作流先执行 libre 与 baidu 的质量检查，再构建签名 APK 和 `SHA256SUMS.txt`，将正式 Release 设为 Latest。实际结果以对应标签的 GitHub Actions 和发布附件为准。
