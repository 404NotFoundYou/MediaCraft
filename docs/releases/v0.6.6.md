# MediaCraft v0.6.6 百度版

发布日期：2026-11-18。应用版本为 `0.6.6+190`，正式标签为 `v0.6.6`。

## 界面调整

- 图片和视频查看器的操作栏、视频控制条、详情页及内置编辑器统一使用浅色主题。
- 页面采用纸面浅底、白色卡片与操作面板、深色文字和图标，保留绿色强调色。面板不再透出媒体画面的颜色，减少背景杂乱。
- 从应用深色主题进入查看、详情和编辑区域时，这些区域也保持浅色；系统栏图标随浅色背景使用深色。
- 移除设置首页正文顶部的搜索栏，分类直接展示，右上角放大镜仍可搜索设置。
