# MediaCraft 0.4.0

- 重新设计为图库优先界面，首屏展示媒体概览、最近照片和视频，并保留重复项扫描、重命名、操作记录与设置入口。
- 新增媒体详情：查看预览、文件名、相册路径、拍摄时间、尺寸、格式、文件大小和视频参数。
- 照片按需读取 EXIF GPS，视频按需读取位置元数据；位置读取只在打开详情时发生，不会拖慢图库列表或重复扫描。
- 使用 Android 系统地理编码服务把坐标解析为分层地名和完整地址，展示度分秒坐标，并支持复制十进制度坐标。
- 支持复制坐标、按需加载 OpenStreetMap 地图，以及在外部地图查看拍摄位置。
- 无 GPS、媒体位置权限不足、地名查询超时、地理编码不可用和地图加载失败均有明确回退；即使无法获得地名或地图，仍保留可用坐标。
- HTML 原型用于界面评审，包含明确标注的示例媒体、示例地名和示意地图，不读取真实媒体。Android 应用使用获准访问媒体中的真实位置数据。

## 隐私与位置边界

媒体扫描、重复检测、摘要计算、EXIF 和视频位置元数据读取均在本机完成，不上传照片或视频。系统地理编码服务可能联网发送坐标；只有用户点击加载或外部查看地图时，才会向 OpenStreetMap 发送坐标。

地名和地址由设备上的 Android 系统地理编码服务返回，其可用性、语言和精度取决于设备、网络与服务数据。坐标可以定位到附近区域，但应用不承诺一定识别到某个具体景点、建筑或门牌。

## 安装与兼容

正式 APK 延续既有正式发布签名，可从先前正式版本覆盖升级。最低支持 Android 11（API 30），正式 APK 面向 ARM64 Android 设备。

下载 `MediaCraft-0.4.0.apk` 并按系统提示安装。`update.json` 供应用内更新读取，`.sha256` 用于独立校验 APK。详细验证范围、通过项和未验证边界见 [0.4.0 验证记录](v0.4.0-validation.md)。

## 已知验证边界

Android 16 无窗口模拟器中，GPS、地名查询和地图瓦片请求已验证；地图截图仍是白色画布，尚不能确认真实地图像素绘制。地图视觉效果和媒体位置权限的拒绝交互仍需真机验收。
