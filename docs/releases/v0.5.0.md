# MediaCraft 0.5.0

- 按 `docs/ui-prototype.html` 重构 Android 信息架构，默认进入图库首页。
- 新增原型一致的绿色 Hero、影像概览、响应式媒体网格、筛选入口和重复项摘要。
- 桌面端使用侧栏，移动端使用图库、重复项、重命名、设置底部导航；活动记录从顶部更多菜单进入。
- 媒体详情改为沉浸式详情层，提供真实照片/视频预览、元数据、位置详情、分享和重复项复核入口。
- 重命名、活动记录和设置页面改为原型风格白色圆角面板，并保留既有业务流程与授权边界。
- 修正媒体列表刷新和最近媒体排序，确保拍摄时间较新的照片与视频优先展示。

正式 APK 继续使用既有发布签名，最低支持 Android 11（API 30），目标 SDK 36，面向 ARM64 Android 设备。下载 `MediaCraft-0.5.0.apk`，并使用同目录的 `update.json` 与 `.sha256` 校验安装包。

详细构建、测试和发布证据见 [0.5.0 验证记录](v0.5.0-validation.md)。
