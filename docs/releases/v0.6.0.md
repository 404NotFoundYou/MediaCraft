# MediaCraft v0.6.0

发布日期：2026-11-12

## 本次内容

- 将 MediaCraft 重建为基于 Aves 完整源码的 Flutter Android 图库工程。
- 保留图片、视频、元数据、搜索、地图、媒体查看器和 Android 平台集成模块。
- 增加照片和视频完全重复检测、回收站恢复校验、过期结果拦截和即时列表刷新。
- 接入 `liquid_glass_widgets 1.17.2`，并保留 Aves BSD 3-Clause 与第三方许可证通知。
- 固定 Flutter 3.47.8 和 libre flavor 的本地构建入口。

## 验证结果

- Flutter 测试：85/85 通过。
- Android JVM 测试：18/18 通过，0 跳过。
- 静态分析：实际启用的 16 个分析目录均为 `No issues found`。
- 真机：Honor YOK-AN10，Android 12；libre debug APK 覆盖安装和冷启动成功。
- 业务检查：照片/视频完全重复项扫描、回收站移入与恢复、本地 H.264 播放通过。

完整记录见 [重建与验证记录](../rebuild-and-validation.md)。

本版本 GitHub Release 附带的是 `MediaCraft-1.15.10-libre-debug-arm64.apk` 及其 SHA-256 文件。该 APK 是调试签名包，用于复现当前源码验证结果；正式签名、Play/Izzy flavor、商店上传、其他设备和网络媒体仍未验证。
