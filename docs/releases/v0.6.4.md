# MediaCraft v0.6.4 百度版

发布日期：2026-11-17。应用版本为 `0.6.4+188`，GitHub 发布标签为 `v0.6.4`。

## 更新内容

- 更新 MediaCraft 品牌、应用图标与纸白/森林绿主题，适配深色界面。
- 默认主导航调整为“媒体 / 相册 / 探索 / 工具”，保留已有用户的导航、主题和快捷操作设置。
- 探索页整合已有地图、国家、地点、标签、媒体类型与高级筛选；工具页整合重复清理、目录、统计、回收站和设置。
- 统一媒体库、相册、搜索、地图、统计、隐私与设置页面布局，优化照片查看器、视频控制和内部编辑器。
- 优化重复清理的扫描状态、逐组复核和底部操作区，继续在移动前执行最终字节复核。
- 修复大字体导航溢出、深色查看器系统栏和时间文字对比度，以及 TV 媒体选择模式中的维护工具入口。
- 更新帮助、项目介绍和商店截图，保留原始版权、开源许可证与第三方归属。

## 安装包

本次 GitHub 正式发布使用百度地图 flavor，包名为 `com.mediacraft.app.baidu`；本地开发默认仍为 `libre`。

| ABI | 文件 | versionCode |
| --- | --- | ---: |
| arm64-v8a | `MediaCraft-0.6.4-baidu-arm64-v8a-release.apk` | 18802 |
| armeabi-v7a | `MediaCraft-0.6.4-baidu-armeabi-v7a-release.apk` | 18801 |
| x86_64 | `MediaCraft-0.6.4-baidu-x86_64-release.apk` | 18804 |

大多数近期 Android 手机使用 arm64-v8a。附件 `SHA256SUMS.txt` 用于核对下载文件。正式 Release 设为 Latest，供旧版本检查更新。

## 验证与边界

界面实现阶段的双 flavor 分析、Flutter 测试、Android JVM 测试、Debug 构建和模拟器回归记录见 [UI 验证记录](../design/mediacraft-ui/UI-VERIFICATION.md)。该记录中的 `0.6.3+187` 是发布升版前的调试验证版本。

新标签的 GitHub Release 工作流依次执行 libre 和 baidu 的静态分析、完整 Flutter/启用插件测试、Debug APK 构建和 Android JVM 测试，再构建百度版三个 ABI 的签名 Release APK，校验百度 SDK/C++ runtime 并生成 SHA-256 文件。实际执行结果以该标签的 Actions 记录为准；本地发布核验材料保存在 `artifacts/github-release/baidu-0.6.4/`。

本次新版本签名包没有实体设备回归记录。既有模拟器验证不等同于实体设备、旧 Android、TV 遥控、全部格式、DLNA 或全部地图服务的兼容性验收。商店截图仅更新仓库 metadata，未上传商店。本项目继续遵循 README 的个人学习使用边界。
