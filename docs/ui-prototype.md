# MediaCraft UI 原型

设计日期：2026-11-11。

本轮原型以 Aves 的“图库优先、内容优先、元数据可展开”作为参考，同时保留 MediaCraft 已有的本机去重、重命名和操作记录能力。原型先验证信息架构和关键操作路径，扫描算法、媒体授权和文件处理仍由现有 ViewModel 与领域层负责。

## 页面结构

```text
图库 / 去重
├─ 影像总览：照片、视频、重复组统计
├─ 最近媒体：四列缩略图网格
├─ 媒体详情：沉浸式预览、元数据、拍摄地图和操作入口
├─ 媒体筛选：照片 / 视频 / 全部媒体
├─ 扫描重复项：进入现有扫描流程
└─ 重复项工作台：完全重复 / 照片版本 / 视频版本

重命名
├─ 选择媒体
├─ 自定义或随机命名
└─ 预览锁定后请求系统授权

活动记录
└─ 按次查看成功、失败、跳过、取消和恢复入口

设置
├─ 媒体权限
├─ 扫描范围与相册
└─ 隐私说明
```

## 视觉与交互决策

- 以照片缩略图作为首屏视觉主体，统计卡只提供快速状态，不抢占媒体浏览空间。
- 点击媒体缩略图进入详情层：大图预览在左，文件名、相册、拍摄时间、尺寸、格式、设备和重复项状态在右侧展开。
- 详情层在存在 GPS 信息时展示拍摄位置地图、坐标和地址；无 GPS 时显示未记录位置。
- HTML 使用明确标注的演示地名和示意地图：第一张展示地名，第二张展示无 GPS，第三张展示查询失败与重试。该原型不会读取真实媒体或实时查询地名。
- Android 详情改为按需读取真实媒体的位置，解析地名和地址；在线地图按点击加载，读取权限不足与网络错误各有回退。实现及验证边界见 [位置详情说明](location-details.md)。
- 详情层提供收藏、分享、去重复项复核和更多操作；关闭详情后保留原来的图库位置。
- 主色使用低饱和绿色，表示本机整理和安全确认；警告与失败继续使用橙色和系统错误色。
- 扫描重复项是首屏唯一主操作，避免用户在首次进入时先理解复杂规则。
- 结果页继续按“完全重复 / 照片版本 / 视频版本”分类；版本组保留对比、保留项选择和内容一致确认。
- 底部导航暂保留去重、重命名、记录、设置四个入口，保证现有流程和测试可用；后续可在真机评审后将“重命名”和“记录”合并为工具入口。
- 未授权或无媒体时显示明确空态和授权按钮，不展示虚构的媒体数量或可清理空间。

## 原型验收

1. 首屏能看到图库标题、媒体统计、最近媒体网格和“扫描重复项”。
2. 点击缩略图能打开媒体详情，看到预览、元数据、拍摄地图和重复项状态。
3. 未授权时先看到权限空态；授权后能看到实际媒体缩略图。
4. 照片、视频、全部媒体三个筛选入口能更新扫描范围。
5. 点击扫描后仍进入现有进度、结果分类、人工复核和系统回收站确认流程。
6. 重命名、记录、设置入口和现有自动化测试继续可用。
